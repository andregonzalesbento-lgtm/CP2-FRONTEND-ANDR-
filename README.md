# 🔥 PokéTrade TCG

Uma página web desenvolvida para compra, venda e avaliação de cartas Pokémon TCG.

---

## 🎯 Objetivo

O projeto foi criado como parte de um checkpoint de Front-End, com o objetivo de aplicar conceitos de:

- HTML5 semântico
- CSS externo
- Flexbox
- Organização de layout
- Uso de ícones e fontes externas

---

## 🖥️ Funcionalidades

✔ Exibição de cartas Pokémon  
✔ Seção de cartas raras  
✔ Formulário para venda de cartas  
✔ Barra de busca de Pokémon  
✔ Layout responsivo e organizado  

---

## 🎨 Tecnologias Utilizadas

- HTML5  
- CSS3  
- Google Fonts  
- Font Awesome
